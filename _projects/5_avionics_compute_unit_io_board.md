Modular avionics platform featuring a central processing unit paired with a customizable expansion IO board.

### Key Features

- Stackable bus architecture connecting compute module and IO carrier board.
- Differential signal conditioning for noisy analog sensor lines.
- Flexible GPIO, ADC, SPI, and I2C breakout headers for rapid integration.
